# MultiBot Releases

Public release archive for MultiBot installers and update metadata.

- [MultiBot Desktop source and server](https://github.com/E4B-labs/multibot-desktop)
- [MultiBot Mobile source](https://github.com/E4B-labs/multibot-mobile)
- [Latest release in this archive](https://github.com/E4B-labs/multibot-desktop-releases/releases/latest)

## Downloading

Use assets attached to a published GitHub Release. Match the artifact to your
platform and architecture. Do not run files from untrusted mirrors.

## Publishing

Only maintainers publish artifacts here. Each release should include the
installer and its updater metadata, use a unique increasing version, and link
back to the corresponding source commit.

Release files must not contain credentials, host addresses, user data, debug
logs, or local configuration.
